# Changelog: Easy Menu for Magento 1 / OpenMage

All releases of this extension, newest first. This repository contains the latest release, tagged [`1.1.3`](https://github.com/PluginCompany/magento1-easy-menu/releases/tag/1.1.3); earlier versions are listed for reference and have no tag.

## 1.1.3 — 2019-02-05

- Fixed flat category backend issue
- Fixed issue causing malformed menu item URLs when slash is used as category URL suffix

## 1.1.2 — 2017-12-23

- Minor code changes for Magento Marketplace

## 1.1.1 — 2017-03-01

- Fixed compatibility with new routing system

## 1.1.0 — 2016-10-05

- Added option to use original or custom menu item title
- Original menu item titles are automatically updated when a CMS page, category or product title is changed
- Original menu item titles are adjusted / translated automatically when copied to different store view

## 1.0.6 — 2016-08-30

- Fixed table prefix issue

## 1.0.5 — 2016-01-02

- Fixed CMS page store filter bug

## 1.0.4 — 2015-10-30

- Fixed mobile menu drop-down for RWD theme
- Fixed direct link URL issue

## 1.0.3 — 2015-07-16

- Fixed ACL permissions bug

## 1.0.2 — 2015-06-10

- Fixed single store admin bug
- Added cache refresh on menu save

## 1.0.1 — 2015-03-28

- Added new functionality
- Removed select mass action
- Added cancel option for inserting menu items

## 1.0.0 — 2014-10-31

- First release of Magento Easy Menu extension by Plugin Company.
